# Data availability

This package contains SPARC input files that were present in the supplied working archive:

```text
data/sparc/SPARC_Lelli2016c.mrt
data/sparc/Rotmod_LTG.zip
```

The official SPARC website is:

```text
https://astroweb.case.edu/SPARC/
```

The SPARC page describes the database as 175 late-type galaxies with Spitzer 3.6 micron photometry and high-quality HI/Halpha rotation curves. It also asks users to cite the SPARC master paper when using the data in publications.

Direct source URLs:

```text
https://astroweb.case.edu/SPARC/SPARC_Lelli2016c.mrt
https://astroweb.case.edu/SPARC/Rotmod_LTG.zip
```

Recommended citation:

Lelli, F., McGaugh, S. S., & Schombert, J. M. (2016). SPARC: Mass Models for 175 Disk Galaxies with Spitzer Photometry and Accurate Rotation Curves. The Astronomical Journal, 152, 157.
