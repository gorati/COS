# COS-SGWB csomag audit — rövid magyar összefoglaló

A csomag COS-releváns: egy COS-inspirált log-periodikusan modulált SGWB komponenst
illeszt asztrofizikai power-law háttérrel együtt H1--L1 adatokra.

Az eredmény nem pozitív detektálás. A `astro_only_lvk` modell evidenciája nagyobb,
mint a `cos_plus_astro_lvk` modellé: ΔlogZ ≈ 1.289, Bayes-faktor ≈ 3.63 az
astro-only modell javára. Ez gyenge preferencia az egyszerűbb modell mellett.

COS szempontból a csomag hasznos, mert felső korlát / stresszteszt jellegű:
a COS amplitúdó a futásban ~10^-12 skálára korlátozódik.
