# Methods

This package implements an SGWB parameter-estimation workflow for a combined
COS-inspired and astrophysical model.

## Workflow

1. Generate a `pygwb_pipe` configuration.
2. Fetch public H1--L1 strain data from GWOSC through `gwpy`/`pygwb`.
3. Split the target interval into one-hour windows.
4. Run `pygwb_pipe` on each usable window.
5. Load the resulting point-estimate/sigma spectra.
6. Combine successful windows by inverse-variance weighting.
7. Run Bilby/Dynesty parameter estimation for several model/prior variants.

## Model variants

- `cos_plus_astro_lvk`: COS+astro model with LVK-scale amplitude priors.
- `astro_only_lvk`: astrophysical power-law-only comparison model.
- `cos_plus_astro_wide`: exploratory COS+astro model with wider priors.

The active code fixes:

```text
alpha       = 0
alpha_astro = 2/3
```

The COS term is a log-periodically modulated spectrum. The astrophysical term is
a standard power law.

## Caveats

- This is not a full LVK official stochastic-background analysis.
- No notch list or official collaboration validation is bundled.
- The result is prior-sensitive and should be treated as an exploratory
  upper-limit/stress-test result.
- The bundled PE outputs do not include the intermediate `pygwb` point-estimate
  NPZ files; they must be regenerated by a full rerun.
